# Squealer

Explore SQLite database files.   

[<img src="https://f-droid.org/badge/get-it-on.png"
     alt="Get it on F-Droid"
     height="80">](https://f-droid.org/packages/futuristicgoo.squealer/)

Or download the latest APK from the [Releases Section](https://github.com/FuturisticGoo/squealer/releases/latest).

### Features

- View schema of tables, views, indices and triggers.
- Show data in the tables and views
- Execute queries  
- Export to CSV, JSON and SQL

Read and write commands are supported.
